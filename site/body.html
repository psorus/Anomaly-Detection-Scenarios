Datasets

A dataset counts for a scenario if it is labeled, comes from one of the scenario's applications, has the right modality and carries the annotations the scenario needs, such as severity grades or root causes. Generic collections like ADBench are listed but not counted.

About the codings

Each application is coded for its most common deployment. Where one domain runs two very different setups, such as inline payment scoring and batch investigation, they appear as two applications. The first version was drafted with Claude (Anthropic); entries stay marked as drafts until someone reviews them.

Review entries

Go through the entries, mark each as correct or flag what is wrong, and pick a source that supports it. Your verdicts stay in this browser until you send them. Everything you send at once becomes one pull request that a maintainer merges.

Contribute

Every entry is a small text file in the GitHub repository. You need a GitHub account; nothing has to be installed.

Review entries

Fix a mistake

  1. Open the entry on this site and select Edit on GitHub.
  2. Change the value in GitHub's editor. Allowed values are listed in the file's comments and in properties.yaml.
  3. Select Commit changes, write one sentence on why, and choose Propose changes, then Create pull request.
  4. A bot comments with what the change does to the scenarios. A maintainer merges it, and the site updates a few minutes later.

Not sure how to edit? Describe the problem instead.
